# RiskLensAI (10k-risk-evolution)

RiskLensAI 是一个面向 SEC 10-K 的风险智能分析项目，支持从 filing 提取风险因子、进行对比分析，并在 Dashboard 中查看风险趋势与优先级。  
系统采用前后端分离架构（Cloudflare Pages + Railway），并结合 AWS S3 与 Bedrock 完成数据与模型能力。
