Quick Start

Back to Home

Use this quick path to start from authentication, enter the unified chat workflow, and run business tools only when needed.

Step 1 · Sign In / Sign Up

Use the website Sign in or Sign up button first. Authentication is managed by AWS Cognito.

Step 2 · Open or Continue Conversation

Create a new chat or continue the current one. Empty new conversations remain reusable when you navigate across pages.

Step 3 · Ask in Natural Language

General questions go through normal chat. Business questions are routed by intent to risk, compare, stock, or news tools.

Step 4 · Optional File Attachment

Use the + button in the composer to attach files. HTML supports filing-risk extraction; PDF currently focuses on table extraction.

Step 5 · Review Structured Results

The assistant answers in-chat and can trigger upload/extraction flow so records and dashboards stay in sync.

Step 6 · Iterate with Memory

Follow-up questions reuse conversation context. Stock/news queries are answered in chat without forcing page navigation.

Note: Direct app access still requires a valid Cognito session. If IME composition is active, confirm composition first, then send.
