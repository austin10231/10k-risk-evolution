Core Features

Three production layers matching the current RiskLens workflow and agent behavior.

Layer 1 · Data Foundation

Ingestion & Structuring Pipeline

Support manual/auto filing ingestion plus chat attachment flow, then persist normalized records for dashboard and history reuse.

Powered by AWS S3 + Amazon Textract

📤 Upload 📊 Tables ☁️ S3 Records

Layer 2 · Intelligence Engine

Intent Router, Agent Orchestration & Risk Reasoning

Classify intents into chat/risk/compare/stock/news, orchestrate tool calls via agent runtime, and keep multi-turn memory consistent.

Powered by Amazon Bedrock + AWS AgentCore

Layer 3 · Decision Interface

Monitoring with Market & News Context

Answer stock/news questions directly in chat without forced navigation, while keeping dashboard, records, and conversation state aligned.
